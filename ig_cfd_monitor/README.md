# Harbour · IG CFD 只读监控

运行在自己的 Mac 上，通过 IG REST + Lightstreamer 读取账户，通过 Tailscale Funnel 分享只读网页。代码放 GitHub，API 密钥、登录凭据、资金和历史数据库只存本机。此目录与仓库原有的美股看板独立。

## 连接账户

1. 在 My IG → Settings → API keys 生成并启用 API Key。Live 与 Demo 的密钥和账户不能混用。官方指南：https://labs.ig.com/gettingstarted
2. 双击 `启动监控平台.command`，或创建 `.venv`、安装 `requirements.txt` 后运行 `.venv/bin/python manage.py install`。
3. 在 **这台 Mac** 打开 http://127.0.0.1:8787/，填 Live API Key、IG 登录用户名、登录密码。Account ID 可留空；多个 HKD CFD 账户时，配置页显示候选编号，再明确选择。历史起始日填开户日或更早。
4. 保存后自动连接；页面显示结果或经过处理的 IG 错误码。密码错误、密钥无效、待同意协议等错误不会不断重复登录；修正后重新保存。不要将任何密钥发到聊天、GitHub 或网址参数里。
5. 查看 http://127.0.0.1:8786/ 。首次接入必须核对 IG 平台中的权益、现金、保证金、仓位和最近几笔交易。代码和合成测试通过，不等于真实账号已验证。

只选择 `ENABLED`、`CFD`、`HKD` 账户。“个人账户”不能确定法律实体；实际开户实体和保证金平仓规则仍须以用户协议为准。API 本身可能带有交易权限，本项目通过出站端点白名单和公开接口限制实现应用只读，不声称 API Key 是券商层面的只读密钥。

## 分享链接

Mac 上的服务绑定 loopback。只把 **8786** 交给 Funnel：

```sh
/Applications/Tailscale.app/Contents/MacOS/Tailscale funnel --bg --https=8443 --yes http://127.0.0.1:8786
```

分享命令返回的 HTTPS 网址。查看者不需要加入 tailnet；输入共享访问密码后可查看完整余额、持仓和逐笔记录。首页、账户 API、CSV 导出及 SSE 实时推送都需要登录；未配置访问密码时拒绝提供账户数据。

安装后，在运行目录设置或更改访问密码（终端输入不回显）：

```sh
cd "$HOME/Library/Application Support/HarbourCFD"
.venv/bin/python server.py --set-password
```

访问密码只保存为带随机盐的 PBKDF2 摘要，位于权限 0600 的 `state/viewer_access.json`；该文件不上传 GitHub。共享网页通过 HTTPS 使用 HttpOnly、Secure、SameSite Cookie，登录有效期为 12 小时；更改密码会使旧登录凭证失效，已打开的推送流最多再存续 55 秒。连续错误登录受到频率限制。访问密码与 IG 登录密码相互独立。

`noindex` 只是搜索引擎提示。**不要发布 8787 配置端口、state 目录或文件服务。**

旧看板的 HTTPS 443 / 私人 Serve 可以继续保留。仅关闭本项目入口：

```sh
/Applications/Tailscale.app/Contents/MacOS/Tailscale funnel --https=8443 off
```

## 后台运行与本机存储

`manage.py install` 将运行代码复制到 `~/Library/Application Support/HarbourCFD/`，安装当前用户 LaunchAgent `com.harbour.ig-monitor`。后台监督公开读取服务、独立的本机配置服务；登录后自动启动，异常退出后重启。后续安装更新代码时保留运行目录中的账户数据。安装器会按 requirements.txt 核对运行目录中的依赖。

凭据实际位于该运行目录的 `state/credentials.json`，权限 0600，目录权限 0700；文件只允许当前用户读取，但不是加密保险库。SQLite 为 `state/monitor.sqlite3`，按环境和 Account ID 分区。勿把运行目录、备份或截图上传仓库。公开 API 仅返回明确列举的账户/交易字段，不包含登录响应、令牌、用户名、密码或密钥。

服务运行时使用 `caffeinate -i -s` 避免空闲睡眠。关机、合盖睡眠、退出用户会话、断网仍会中断采集，Tailscale 不代替云服务器。

```sh
.venv/bin/python manage.py status
.venv/bin/python manage.py stop
```

## 数据及刷新口径

- 行情：使用当前 IG `PRICE:{accountId}:{epic}` / `Pricing` adapter，持仓自动加入，登录时读取 IG 内前五个自选列表；最多 38 个合约，持仓优先。未订阅数量单独显示。尚未确认的关键指数不自行选定。
- 推送使用 `ACCOUNT`、`TRADE` 和 `PRICE`。后台至网页 SSE 最高每 250 毫秒推送一次；这是展示更新上限，不是 IG 到屏幕的延迟保证。页面断流会标为中断并尝试重新连接。
- 账户、持仓和挂单：约每 20 秒 REST 对账；交易推送触发较快对账（最短 5 秒间隔）。REST 串行限速，不随访问人数放大 IG 调用。SDK 自动重连，令牌失效重新认证，限流退避。
- SDK 缺失或进入断开终态时，独立恢复逻辑按 30、60、120、240、300 秒上限退避重建行情订阅，复用当前会话令牌；SDK 已在连接、停滞或自行重试时不额外重建。账户 REST 对账继续运行，页面独立显示账户同步与行情重连状态，行情断开不被包装成已确认实时价格。
- 账户/报价超过 30 秒或时间戳缺失会标注。休市和延迟报价仍保留原状态，不标为可用实时行情。
- 账户权益采用 IG 现金余额 + 浮动盈亏，推送明确提供 EQUITY 时采用该字段；资金、保证金不互相替代。逐仓 HKD 盈亏在点值/汇率未核验前不估算。
- 权益曲线只记录接入后的真实快照；快照间隔通常 30–40 秒，超过两分钟的缺口断开绘制，不生成合成历史。
- 历史以 28 天窗口、分页读取，保存交易流水、账户活动和推送事件；相同原始记录哈希去重。不同来源描述同一笔交易时保留来源，不能将总条数当成交笔数。网页每页 50 条，CSV 导出全部已读取记录。
- 启动时重新覆盖用户指定的历史范围，运行期间每五分钟回查最近两天。覆盖状态只说明 API 请求区间，不等于月结单已核对、开户以来绝对无缺失。API 错误、缺少分页元数据会显示未完成。
- SQLite 实际使用 events、snapshots、metadata 三张表，由 storage.py 创建。工作目录中旧 schema.sql 只是原型设计参考，不用于生产迁移。

## 产品 K 线、趋势图与绘图

从持仓或市场产品打开图表，选择 1、5、15、30 分钟、1 小时、日、周、月周期，并切换 K 线或收盘价趋势线。图表使用 IG 历史 **Bid** OHLC；空仓实际平仓参考 Ask，不能将 Bid 图直接视为可成交价。止损、止盈参考线沿用已同步持仓数值；开仓改以成交点展示。

历史按需读取，首次和每次“加载更早”最多申请 200 个价格点，按环境、账户、产品和周期保存到本机缓存；每产品每周期最多保留最近 20,000 根，重复查看复用缓存。IG 默认历史价格配额为每周 10,000 个数据点，与账户 REST 调用频率限制独立。可用历史随产品和周期变化，1 分钟通常约 40 天，分钟及小时级数据通常约 360 天，日线官方参考范围最长约 15 年；周、月线以接口实际结果为准。页面显示实际读取范围、更新时间、额度和错误，不把缓存起点称为产品最早历史。达到配额或接口覆盖边界时保留已读取数据，不合成缺失行情。 查询区间按 IG 响应中实际观察到的账户本地时差转换，蜡烛时间统一以 UTC 保存、香港时间显示；若接口显示混合或变化的时差，停止该次翻页并提示，不猜测时区。

图表打开时自动检查缓存：1 分钟周期最快每 60 秒申请官方增量 K 线，其他分钟和小时周期每 300 秒，日线每 900 秒，周/月线每小时；临近配额时暂停自动刷新，已有缓存继续显示。当前 Bid/Ask 及独立“实时 Bid”参考线沿用行情推送，历史 OHLC 不由单个报价伪造。久未查看后出现的未核对区间会显示提示，趋势线在这些区间断开。

开仓与平仓以只读成交圆点显示在 IG 图表的真实时间、成交价格处：绿色为买入，红色为卖出，实心为开仓，空心为平仓；卖出开空与买入平空也按此区分。细点半径 2.75px、描边 1px，点击命中范围仍为 12px。逐笔成交数量标签和从真实成交位置延伸至右侧价格标记的水平虚线分别可开关，同价成交保留笔数。数量是自身 IG 成交合约数量，不是行情市场成交量。手形模式悬停或点击圆点查看时间、价格、数量和成交编号；同一位置的多笔记录一并列出。切换周期、平移缩放与导出 PNG 保留点位、数量和价格线。成交点不属于可编辑的共享画线，不会造成未保存草稿。

成交点只使用当前持仓和已采集历史中能确认产品、UTC 成交时间及价格的执行记录，不将挂单、改单、失败或资金流水当成成交，不使用当前报价推算成交价。平仓买卖方向还须与同一仓位的唯一原始方向交叉核验，方向不明或冲突时省略并提示。原始成交数量无法核实时显示未确认，不将部分平仓后的剩余持仓量冒充开仓成交量。仅在已加载且可确认覆盖的历史范围显示，数据缺口、范围之外或字段不足会提示未展示数量；这不代表完整成交记录已与月结单核对。交易点来自本机数据读取，不因查看人数或切换周期增加 IG 成交历史请求。TradingView 参考图使用独立外部行情，私有成交点只绘制在 IG 图表中。

趋势线、水平线、矩形和自由画笔按时间及价格坐标保存；切换周期或缩放时重新定位。使用“保存标注”保存到服务器；未保存草稿在当前页面内切换产品、周期和导航时保留，关闭页面前会提示。支持撤销/重做、移动、调整颜色/粗细、删除、清除及导出 PNG。标注按产品共享，所有持访问密码的查看者可查看和编辑。标注只写本机图表存储，不向 IG 发送交易指令。并发编辑使用版本校验，发生冲突时提示重新加载，不默默覆盖其他查看者的标注。

图表库为本机提供的 Lightweight Charts，保留 TradingView 署名和许可证；打开图表无需从公共 CDN 加载图表代码。图表缓存与标注属于私有运行状态，不随源码上传 GitHub。

### TradingView 分析图表

图表页另提供按需展开的 TradingView 参考图，使用 [react-ts-tradingview-widgets](https://github.com/JorrinKievit/react-ts-tradingview-widgets) 1.2.8 的 `AdvancedRealTimeChart`，以 React 18.3.1 + TypeScript 构建本地入口。产品、八个周期及 K 线/趋势线选择随 IG 图表联动；没有明确映射的产品显示待配置，不猜测代码。当前原油参考 `OANDA:WTICOUSD`，日本 225 参考 `OANDA:JP225USD`。

参考图的数据由 TradingView 及图中标示的数据源提供，可能与 IG 的 CFD 合约、交易时段、点差和报价不同。[官方 Widget 不支持传入自有行情](https://www.tradingview.com/widget-docs/faq/data/#can-i-display-my-own-data-in-the-widgets)，因此 IG 图表仍用于查看真实 Bid 历史和持仓参考线。TradingView 工具栏提供其自身的绘图与指标；其中的画线不保存到本项目共享标注库，不承诺跨设备保留。需要共享和持久保存时，使用 IG 图表的“保存标注”。

仅展开参考图时请求 TradingView。第三方加载脚本在无同源权限的本地 sandbox 文档内运行，父页只接受来自当前 iframe、带当前随机标识且匹配公开产品/周期的图表地址，再将严格校验的 TradingView HTTPS 图表放入独立跨源 iframe。第三方脚本不在账户页面执行，也不接收账户编号、金额、持仓数量、凭据或标注。入口 HTML 仍要求登录；唯一免登录的新增资源是无私有数据的本地构建 JS，供 opaque sandbox 加载。主页面的远程许可仅限 `frame-src` 的三个 TradingView 域，账户接口不增加跨域许可。

构建产物已随源码提供，运行 Python 服务不需要 Node。修改 React/TypeScript 入口后重新构建：

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm run build
```

依赖版本和完整性哈希锁定在 `frontend/pnpm-lock.yaml`；许可证及来源记录位于 `web/vendor/tv-reference.LICENSE` 和 `web/vendor/tv-reference.SOURCE.txt`。

## 风险提醒与日线

按用户选择：`权益保留比例 = 当前权益 / 已核验累计入金`，`亏损比例 = max(0, 1 − 权益保留比例)`。亏损达到 60%（保留比例不高于 40%）触发网页提醒。累计入金 30,000 HKD 对应权益线 12,000 HKD；追加已核验入金后自动重算。**提款也降低本口径的权益，因此此指标不等于净交易收益率。** 不执行订单、止损或强平。

同时显示累计 Profit 金额 `权益 − 累计入金总额` 及百分比 `(权益 − 累计入金总额) / 累计入金总额 × 100%`。盈利显示正值，亏损显示负值，60% 提醒独立保留；每个账户使用自己的已核验入金分母。账户、入金或前端连接过期时不显示有效 Profit。此口径包含未实现盈亏及提款影响，不等同已实现交易收益。

累计入金按配置的 `history_since` 起，通过 IG DEPOSIT 筛选分页读取所有明确 DEPO 记录，只有全部窗口完成才发布总额。`HK` / `HKD` / `HK$` 明确归一为 HKD，拒绝未核验币种或金额。引用号去重、冲突拒绝、重启后增量补查；入金覆盖的开始时间与最新核验时间展示在网页，不能据此断言配置日期之前没有入金。IG `WITH` 可能是隔夜利息，不自动视作提款。

账户、持仓和挂单独立更新；一个组件失败不会丢弃其他有效数据。GET 网络瞬断有界重试；证书验证保持开启，认证错误和会话写入不盲目重试。权益超过 30 秒、入金核验超过 6 分钟，分别显示过期或待核验。权益不高于已用保证金时单独提醒，这不是券商强平规则。只有网页内提醒，未配置短信、微信或手机后台推送。

权益曲线每个香港日期只保留当日最后一笔有效观测；今天标记暂值。没有采样的日期留空并断开连线，不补造历史。日末点是最后观测，并非保证取得 IG 官方结算净值；观察期回撤及日间权益差均包含出入金影响。

## 按品种的开仓均价

持仓页按 EPIC、币种、到期分组，以 Σ(开仓价 × 未平仓数量) / 总数量计算开仓均价。多仓、空仓分别展示总数量、笔数和加权均价，不把多空相抵后计算一个没有清晰含义的成本价。数据缺失不以零代替；明细保留用于核对。

## 仓位风险与量化（P0 / P1）

`/#quant` 提供按 EPIC 聚合的多空数量、总/净名义额、净/总 HKD 点值、集中度、有效总杠杆、逐仓止损距离与追加损失估计。实际权益、保证金及可用资金仍来自 IG。合约规格来自 `/markets` v3，每小时按需刷新；持仓优先，过期阻断情景。当前支持具有单一可核验合约币种的线性指数、商品、外汇 CONTRACTS，其他品种显示待核验。

点值 = `valueOfOnePip / (onePipMeans 数字步长 × scalingFactor)`，不重复乘 contractSize。非 HKD 换算采用 `1 / baseExchangeRate`，明确标记估算。逐仓合计与 IG 账户浮盈亏核对，容限为 max(50 HKD, |IG浮盈亏|×5%)；超出容限、账户/持仓/报价/规格过期时暂停压力结果，不声称逐仓估算精确等于 IG。

8 个周期提供已确认收盘 Bid K 线的 EMA20/50、Wilder ATR14 / RSI14、前 20/60 根高低区间、均线状态和带失效条件的上行/区间/下行情景。末根始终排除，至少 61 根已收盘数据。按确切 EPIC 的常规参考时段扫描内部缺口：美国原油识别每日暂停，日本 225 现货不套用原油暂停或东京午休；纽约时区逐日处理夏令时。缺口只有全部落在常规休市内才被解释，混有交易时间、参考规则冲突、过旧样本、API 错误或配额限制仍暂停结论。页面显示具体原因、缺口香港时间和时段依据。IG 未返回完整开市日历，参考规则及节假日限制见 [交易时段核验](TRADING_SESSIONS.md)。相关性只使用同起止 UTC、正价格的收益区间，至少 30、最多 60 个；数据受限则不发布相关系数。

压力表支持 ±1/2 ATR、产品净敞口逆向 ATR、百分比/点数冲击、外币兑 HKD 变动、价差扩大与额外成本假设，展示权益变化、情景权益、保证金不变假设下的可用资金和距 60% 提醒线的距离。所有产品同时受到所选冲击，不模拟止损成交；跳空、滑点、非线性产品与保证金调整不在该模型内。ATR 受限时可改用点数/百分比，但其他数据校验仍须通过。

已入账融资、佣金、股息、换约、明确提款、已实现损益和待分类款项分栏；不把未知未来融资费当作 0。不能可靠匹配合约的融资款项只按账户归集。到期/换约信息按 IG 字段展示，缺失明确标记。50% 保证金使用、60% 单品集中度、10% 观察期回撤是说明性的观察阈值，不改变用户指定的 60% 累计亏损线。

未实施用户排除的 P2：没有概率 Forecast、训练模型、回测胜率或自动交易。成交量来源不明时不使用 VWAP / OBV。

## 新闻与官方事件

## 多个独立 IG 登录账户

在运行后台的 Mac 打开 `http://127.0.0.1:8787/`，点击“新增账户”。填写显示名称、Live/Demo、该登录名自己的 API Key、IG Identifier、密码、历史记录起始日；有多个 HKD CFD 子账户时指定 Account ID。保存后后台自动发现并连接，无需重启。最多保留 8 个配置，当前支持不同登录名的 HKD CFD 账户。同一环境下的重复登录名或 API Key 会被拒绝，避免重复登录与订阅。

- 原账户保留 `state/credentials.json`、`monitor.sqlite3`、`charts.sqlite3`，无破坏性迁移。
- 新账户使用随机配置 ID，在 `state/profiles/<id>/` 内分别保存权限受限的凭据、连接状态、流水/日线与 K 线/标注数据库。API Key、用户名、密码和会话 token 不进入公开 API 或 GitHub 导出。
- 编辑现有配置时，密钥、用户名、密码留空即保留；环境或登录主体变更必须新增账户。取消“启用”可暂停该账户，保留历史。每个账户拥有独立的 REST 限速器和一条行情连接，共享官方新闻/日历采集。
- 看板顶部账户菜单按 `?account=<id>` 切换整个页面；状态、SSE、流水、CSV、量化、K 线、成交标记、标注读写都按 `profile` 路由。未知 ID 返回 404，不回退至主账户。页面切换会清理旧账户请求和内存状态；未保存的画线保留浏览器离页提示。
- “多账户总览”每 5 秒检查全部账户，Live/Demo 分开。只在同环境的全部已启用账户资金新鲜且币种为 HKD 时合计资金；入金基准未核验时不合计入金。暂停账户不计入汇总。合计资金不能用于跨账户抵扣保证金。
- 各账户独立使用其已核验累计入金计算 60% 亏损线；不把主账户 HKD 30,000 套到其他账户。顶部会提示任何账户触线或待核验。仍只读，所有交易继续在 IG 手动完成。
- 所有配置账户沿用现有分享链接和访问密码；没有分用户可见范围。新增真实账户需要用户在本机填写凭据，合成测试不代表第二个真实登录已经成功。

验证：`python -m unittest discover -s tests -p 'test*.py'`；Node 运行 `tests/test-accounts-ui.mjs`、`tests/test-chart-ui.mjs`、`tests/test-risk-ui.mjs`。多账户测试覆盖身份/密钥去重、暂停、数据/画线隔离、各 API 的账户路由、真实/模拟分离、过期汇总门控和独立亏损提醒。
